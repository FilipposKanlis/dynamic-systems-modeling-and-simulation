# Simulation and Modeling of Dynamic Systems

MATLAB implementations of dynamic system modeling, simulation and system identification methods developed for the Simulation and Modeling of Dynamic Systems course at the Department of Electrical and Computer Engineering, Aristotle University of Thessaloniki (AUTH).

## Laboratory Assignments

### Assignment 1 – System Identification and Least Squares Estimation

- Mass-Spring-Damper System Modeling
- RLC Circuit Modeling
- Least Squares Parameter Estimation
- Transfer Functions and Linear Parameterization
- Signal Filtering and Filter Pole Selection
- MIMO System Identification
- Measurement Error and Outlier Analysis

### Assignment 2 – Adaptive System Identification

- Gradient-Based Parameter Estimation
- Parallel and Mixed Identification Structures
- Adaptive Gain Selection
- State-Space System Modeling
- Measurement Noise Analysis
- Parameter Convergence Analysis

## Technologies

- MATLAB
- Control System Toolbox
- Numerical Integration (ODE45)
- Ordinary Differential Equations
- Scientific Data Visualization
